## 技术与素材

产品使用 Three.js 原创键盘几何和渲染图，图标使用 Lucide。界面动效使用 CSS、Web Animations API、本机 Canvas 及弹簧计算。共享元素记录进入和离开时的真实矩形；布局过渡计算增删前后的位置。根据浏览器的减少动画偏好停用装饰性运动，保留静态反馈和实际操作。

参考 [MDN 的 Web Animations API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API)、[视图转场说明](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API)、[GSAP Flip 的布局动画文档](https://gsap.com/docs/v3/Plugins/Flip/)及 [Chromium 原生弹层动画说明](https://developer.chrome.com/docs/modern-web-guidance/guides/ui-behaviors/animate-to-from-top-layer)中关于动画时序、前后几何和弹层可操作性的设计方法。实现依靠本仓库源码。只公开原片链接与时间索引，商品图、样品数据、声音和网页样式自行制作。
